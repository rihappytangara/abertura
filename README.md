# Sorteio Hot Wheels

1. Coloque as imagens em /assets.
2. Nomeie como:
   1.png, 2.png, 3.png ...
3. Ajuste TOTAL_PARTICIPANTS em script.js.
4. Hospede no GitHub Pages.

Recursos:
- Sorteio aleatório completo.
- Destaque visual do participante atual.
- Botão 'Próximo Participante'.
- Cronômetro de 1 minuto.
